# Jan's Practice Map

Jan's client dashboard for Personal Training for Meditators — a small installable web app (add it to the home screen from the browser's share menu).

Same build as Joe's map: one `index.html`, a service worker for offline use, and a manifest with the shared Practice Map icon. Copy is editable by opening the page with `#edit`; a `copy.json` beside `index.html` overrides any key for everyone.

Recordings and form demos stream from YouTube (unlisted). Notes go to Tanner's inbox through FormSubmit, with a mail-app fallback.
